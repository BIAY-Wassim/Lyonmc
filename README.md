Plugins du serveur LyonMC (par wassdead), pour Purpur / Paper 1.21.8.

- **LyonAchievements-7.0.0.jar** : succès, grades, missions, **métiers**, saisons, boss, économie, hologrammes, menus, chat (mentions, [objet]), site.
- **HUB-1.8.1.jar** : le monde du hub, son inventaire, le podium de PNJ (aussi pour les métiers), le village de départ, **le parkour**.
- **COMMUNAUTE-1.1.0.jar** : premiers pas, **centre d'aide (/aide)**, **règlement (/regles)**, astuces, votes, parrainage, fidélité, **amis, messages privés, signalements, modération**.
- **lyonmc-site.zip** : le site lyonmc.fr (pages Rejoindre, Règlement, FAQ, Actualités, métiers, pages légales).

Mise à jour : arrêter le serveur, remplacer les .jar dans `plugins/` (supprimer les anciens), redémarrer.
Les données des joueurs sont conservées, les nouveaux réglages s'ajoutent tout seuls aux fichiers de config.

Site : extraire `lyonmc-site.zip` dans le dossier `siteweb` (sans toucher au dossier `data`),
ou lancer `bash installer-site.sh` (dossier `deploy` du dépôt).
